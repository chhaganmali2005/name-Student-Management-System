# Student Management System

## About the Project
The Student Management System is a Java-based project developed to manage student information. This project helps beginners understand Java programming and basic project development.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)

## Features
- Student information management
- Simple Java application
- Beginner-friendly project structure

## How to Run the Project

1. Install the Java JDK.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Open the terminal in the project folder.
5. Compile the Java file:

   ```bash
   javac StudentManagementSystem.java
   ```

6. Run the program:

   ```bash
   java StudentManagementSystem
   ```

## Project File
- `StudentManagementSystem.java` — Main Java source file.
